# README.md

This webpage pays homage to the programming that is behind
most modern websites. This design is no accident: it is
purposefully designed like this.

## What's inside

It is split into Index, About, Projects, and Contact.

- **index.tsx**     → Index is the home page; the overview of
                     everything this website has.
- **about.md**      → About has everything about me and a
                     little something for the projects I've made.
- **projects.json** → Projects is a more detailed explanation
                     of each project, and it talks about
                     everything related to said project.
- **contact.ts**    → Contact has a list of contacts and a
                     little form where someone could message
                     me directly.

## Two views

The Frontend view is a regular website. This one, the
Backend, is the code-editor version. Flip between them with
the switch at the top.

## Try it

Aside from the contact form, many other parts of the website
are interactable. Try running commands in the command terminal:

```sh
help        # every command
neofetch    # the short version of me
git log     # project history
run projects.json
```
